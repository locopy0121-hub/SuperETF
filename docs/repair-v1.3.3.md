# SuperETF v1.3.3 — 證券名稱自動填入

## 修護範圍
- 新增持倉及新增股息的證券代號欄位，輸入停止約 320ms 後自動查詢名稱。
- 保留前導零與英文尾碼；`00406A` 對應「主動中信台灣收益」。
- 查詢來源依序為：少量官方核對清單、富果 Market Data v1.0 `GET /stock/intraday/ticker/{symbol}`、TWSE 上市清單、TPEx 上櫃清單。未設定富果 API Key 仍可由交易所公開資料查詢。
- 限制合法代號（4–6 碼數字、可選單一英文字尾），不猜測查無資料代號。
- 同一欄位輸入變更即取消過時請求，結果僅在代號仍相同時寫入，使用者自己改過的名稱不會被覆蓋。
- 查詢中、已填入、查無資料狀態提示；儲存時空白名稱先重新確認，仍無法取得就要求手動輸入。
- 強化手機表單欄位最小寬度，避免新增狀態提示擠壓輸入框。
- 保留既有持股、股息、富果設定的 localStorage 資料；只變更新增表單及新增工具與測試。
- GitHub Actions 的 APK 打包新增 `security-lookup.js` 並以版本 `v1.3.3` 命名。

## 驗證
- 新增證券名稱工具測試：代號正規化、00406A 名稱、富果 ticker 對應驗證、TWSE/TPEx 清單解析、來源優先序、手動名稱保留、過時請求防護。
- 原有富果 API 與六頁 UI 合約測試需一起通過後才產生 APK。

## 限制
- TWSE 與 TPEx 公開 API 在 Android WebView 是否可跨來源存取，仍受伺服器 CORS/網路條件限制；此時提示手動輸入。
- 目前生成 Debug APK，既有安裝版本的簽章一致性尚須實機驗證。
