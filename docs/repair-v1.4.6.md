# SuperETF v1.4.6 — 持股新增即時聯動／紅漲綠跌黃平

## 問題與修護
1. v1.4.5 新增庫存保存後，只更新庫存、損益牆的當前 DOM，並且只在盤中呼叫一次全市場同步；因此夜間新增的 00406A 仍呈現「等待行情」。修正為先保存持股與交易，再立即刷新行情牆、庫存、損益、股息與已顯示圖表，隨後逐檔向 TWSE 官方最近交易日、富果 REST 與 Yahoo 備援取得價格，結果回來後再次同步所有頁面。不創造不存在的價位。
2. 日期合法性原先只接受當天 13:45 後或假日舊資料，週四凌晨 00:45 會拒絕週三正式收盤。現在取最近已完成交易日：晚上／隔日盤前以昨一交易日為準、當天盤後依今天正式收盤，以證交所標註的日期比對，禁止舊收盤冒充新收盤。
3. 加入有效代號分類：以 00 開頭的 ETF（含 00406A 等帶 A 尾碼）納入 ETF 行情篩選與 LIVE 訂閱類別，仍使用真正證券代號。
4. 股價上漲、日損益／未實現損益、線圖上行一律 **紅色 #ef4444**；下跌／虧損 **綠色 #22c55e**；平盤／零損益 **黃色 #facc15**；未知行情 **灰色**。買賣操作和 API 連線狀態不與損益顏色混淆。
5. 新增持股後顯示「正在取得」「已更新」或「無有效報價」訊息。盤中 LIVE 繼續逐筆推送，盤後 TWSE 及備援資料僅作收盤，絕不假裝為 LIVE。

## 安裝簽章限制
- v1.4.5 預覽版的 Runner Debug 簽章憑證沒有保存，下一次 Actions 使用不同憑證，不可直接覆蓋 `com.locopy.superetf.preview`。
- 因此 v1.4.6 的獨立測試版套件 ID 為 `com.locopy.superetf.preview.v146`，可與 v1.4.5 預覽版及正式 App 並存，不會卸載或覆蓋舊持股資料。
- 新預覽版**不會自動取得舊預覽版的本地資料**；若要跨版本保留持股，請先從已保留舊 App 中安全導出資料，或在 GitHub Actions 配置固定簽章與正式資料遷移後再升級。
- 維持正式 release 的 GitHub Secrets 固定憑證門檻，沒有金鑰不生成冒充可升級的正式版。
